# Розділ «Games» → гра «Мафія»: 3 варіанти сценарію (ТЗ на вибір)

> Мета розділу: короткі ігри, щоб дитина могла переключитися й відпочити.
> Вимога до «Мафії»: 5–8 гравців (можна більше), але гра має нормально працювати з **мінімальною** кількістю людей.

---

## 0. Ключове рішення для всіх варіантів: **застосунок = ведучий**

У живій «Мафії» один із присутніх не грає, а веде гру. Якщо людей лише 5, ведучий «з'їдає» одного гравця.
Тому в усіх трьох варіантах **ведучого замінює сайт**, і грають усі присутні.

### Режим MVP: «Один телефон по колу» (pass-and-play)
- Гра йде на **одному пристрої**, без сервера й без реєстрації кожного гравця.
- Таємні дії (подивитися роль, нічний хід, таємне голосування) виконуються так: екран «Передай телефон гравцю **Оля**» → Оля натискає й **утримує** кнопку «Показати» → бачить свою роль / робить хід → «Готово, передай далі».
- **Нічне коло для всіх.** Уночі телефон отримує **кожен** живий гравець, а не лише ті, хто має нічну дію. У мирних жителів теж є «хід»: наприклад «Кого ти підозрюєш?» (ця відповідь потрапляє в статистику наприкінці гри). Так по тому, хто довше тримав телефон, не можна здогадатися, хто мафія.
- **Мінімальний час на екрані ходу:** кнопка «Готово» стає доступною через 5 с. Тоді всі тримають телефон приблизно однаково довго.
- Тексти ведучого показуються на екрані великим шрифтом. Опційно їх можна озвучувати через Web Speech API (`uk-UA`). Якщо українського голосу в браузері немає, гра просто лишається з текстом.
- Стан гри зберігається в `localStorage`, тож після випадкового оновлення сторінки гра продовжиться.

### Режим 2 (наступна фаза): «Кожен зі свого телефону»
Кімната з кодом, кожен гравець заходить зі свого пристрою. Для цього потрібен сервер (API + опитування стану або SSE). Логіка гри та сама, змінюється лише транспорт. **Тому ядро гри від самого початку пишемо як чистий редʼюсер** `(state, action) → state` без прив'язки до UI.

### Тема оформлення (тексти й іконки, без зміни механіки)
Оскільки аудиторія — діти, пропоную дві «шкірки» з однаковими правилами:

| Механіка | Тема «Місто» (класична) | Тема «Ліс» (дитяча) |
|---|---|---|
| Погані | Мафія 🕶️ | Вовки 🐺 |
| Лікує | Лікар 🩺 | Знахарка 🌿 |
| Перевіряє | Комісар 🔎 | Сова 🦉 |
| Мирні | Мирні жителі 🏠 | Зайчики 🐰 |
| Вибуття вночі | «Мафія відвідала…» | «Вовки забрали в нору…» |
| Вибуття вдень | «Місто вигнало…» | «Ліс вирішив: … іде з галявини» |

Слів «вбили», «труп» і подібних не використовуємо. Гравець, який вибув, «засинає»: йому показується екран «Ти спостерігач, не підказуй 🤫».
Технічно тема — це словник рядків `ThemeStrings` плюс набір емодзі чи картинок.

Другою грою додати **C**, яка використовує ~70 % того самого коду: лобі, передавання телефону, показ ролі, голосування. **B** я б відклав або зробив як «режим для досвідчених» поверх A.

## Спільне ТЗ для всіх варіантів

### Маршрути
- `/games`: каталог ігор (картки: назва, іконка, «3–10 гравців», «~10 хв»).
- `/games/mafia`: вибір варіанта, якщо їх буде кілька, і правила.
- `/games/mafia/play`: сама гра (клієнтський компонент, `'use client'`).

Чи потрібен вхід (як в інших іграх сайту через `SubjectSignIn`), вирішує власник. Для MVP гра працює без сервера, тож вхід технічно не обов'язковий.

### Лобі (спільний екран)
1. Кількість гравців: степер з межами варіанта.
2. Імена: поля вводу, підставляються «Гравець 1…N». Дублікати й порожні імена заборонені, до 12 символів.
3. Порядок за столом: імена можна перетягувати. Він визначає порядок передавання телефону.
4. Тема: «Місто» / «Ліс».
5. Набір ролей: підставляється автоматично з таблиці варіанта. Кнопка «Налаштувати» відкриває ручне редагування з валідацією балансу.
6. Кнопка «Роздати ролі».

### Роздача ролей
- Ролі перемішуються (Fisher–Yates; можна взяти наявну `shuffle` з `src/components/games/quiz.ts`, а згодом перенести її в `src/lib`).
- Екрани по колу: «Передай телефон: **Оля**» → утримати кнопку → роль, іконка, коротка мета та «що ти робиш уночі» → «Запам'ятав(ла)» → наступний.
- Після останнього гравця з'являється екран «Покладіть телефон у центр столу».

### Голосування (два режими, перемикач у налаштуваннях)
- **Відкрите (за замовчуванням для A і B):** гравці обговорюють, потім ведучий-телефон по черзі питає «Хто голосує проти Олі?», а хтось один відмічає руки. Це швидко й схоже на живу гру.
- **Таємне:** телефон іде по колу, кожен обирає кандидата. Результат показується одночасно.

### Екран кінця гри
- Переможна команда, анімація.
- Таблиця «хто ким був».
- Хронологія ночей і днів («Ніч 1: мафія обрала Петра, лікар врятував Петра»).
- Статистика «Кого підозрювали»: агрегат відповідей мирних жителів з нічного кола.
- Кнопки «Ще раз (ті самі гравці)» та «Нові гравці».

### Модель даних (TypeScript, спільна)
```ts
type Team = 'town' | 'mafia' | 'neutral'
interface Player { id: string; name: string; seat: number; roleId: RoleId; alive: boolean }
interface RoleDef {
  id: RoleId
  team: Team
  nightOrder: number | null      // null: немає нічної дії
  canTarget?: (state: GameState, actor: Player, target: Player) => boolean
}
interface GameEvent { round: number; phase: 'night' | 'day'; type: string; payload: unknown }
interface GameState {
  variant: 'classic' | 'sport' | 'oneNight'
  theme: 'city' | 'forest'
  players: Player[]
  round: number
  phase: Phase                    // окремий union для кожного варіанта
  pendingNightActions: Record<string /*playerId*/, NightAction>
  log: GameEvent[]
  winner: Team | null
}
// Ядро: чистий редʼюсер, який легко покрити юніт-тестами
function reduce(state: GameState, action: GameAction): GameState
```

### Загальні нефункціональні вимоги
- Mobile-first, портретна орієнтація, кнопки ≥ 48 px, великий шрифт.
- Жодних персональних даних: імена лише локально, без відправлення на сервер.
- Кнопка «Пауза / Вийти» на кожному екрані, з підтвердженням.
- Захист від «підглядання»: роль видно, лише поки палець утримує кнопку. Після відпускання екран стає нейтральним.
- Кнопка «Назад» у браузері не відкриває роль попереднього гравця, бо історія фаз не пишеться в `history`.

## ВАРІАНТ A. Класична мафія «Місто засинає»

### Ідея
Мафія вночі таємно обирає жертву, лікар рятує, комісар перевіряє. Удень усі обговорюють і голосуванням виганяють підозрюваного. Гра йде, доки не переможе одна з команд.

### Ролі
| Роль | Команда | Нічна дія | Обмеження |
|---|---|---|---|
| Мафія | Мафія | Разом обирають одну ціль | Якщо мафіозі обрали різних, вибуває ціль першого мафіозі за порядком. Альтернатива: друге коло вибору лише для мафії, налаштування `mafiaConsensus` |
| Лікар | Місто | Обирає, кого лікувати | Не може лікувати ту саму людину дві ночі поспіль; себе — лише 1 раз за гру |
| Комісар | Місто | Перевіряє одного гравця й бачить «мафія / не мафія» | Не може перевіряти себе; бачить історію своїх перевірок |
| Мирний житель | Місто | «Кого підозрюєш?» (на результат не впливає) | — |
| *Опційно (8+):* Чарівниця | Місто | Присипляє гравця: той цієї ночі не діє | Не може двічі поспіль ту саму ціль |
| *Опційно (9+):* Самітник | Нейтральний | Окремо від мафії обирає ціль | Перемагає, якщо лишиться серед останніх двох |

### Розподіл ролей за кількістю гравців
| Гравців | Мафія | Лікар | Комісар | Мирні | Примітка |
|---|---|---|---|---|---|
| **5** | 1 | 1 | 1 | 2 | Найменший збалансований склад |
| 6 | 1 | 1 | 1 | 3 | |
| 7 | 2 | 1 | 1 | 3 | |
| 8 | 2 | 1 | 1 | 4 | можна додати Чарівницю замість мирного |
| 9 | 2 | 1 | 1 | 5 | |
| 10 | 3 | 1 | 1 | 5 | |
| 11–12 | 3 | 1 | 1 | 6–7 | можна додати Самітника |

Чому при 5 гравцях лише 1 мафія: якщо їх 2, то 2 проти 3. Після першої вночі мафія вже на рівних і перемагає одразу. З одним мафіозі місто має 2 спроби вгадати, а лікар і комісар додають ще шанс.

### Цикл гри (стан-машина)
```
lobby → dealRoles → night(1) → morning → dayDiscussion → dayVote → [runoff] → dayResult
       → (перевірка перемоги) → night(n+1) → … → gameOver
```

**Ніч (`night`):**
1. Екран «Місто засинає 🌙». Опційно звучить фонова мелодія.
2. Нічне коло: телефон по черзі отримує кожен **живий** гравець у порядку місць:
   - Мафія бачить своїх партнерів і список цілей (живі, крім мафії), має кнопку «Обрати». Якщо партнер уже обрав ціль, вона показується: «Партнер обрав: Петро».
   - Лікар бачить список живих (з урахуванням обмежень).
   - Комісар обирає ціль і **одразу** бачить результат перевірки.
   - Мирний бачить «Кого підозрюєш?» і список.
   - Кожен екран має мінімальний таймер 5 с перед «Готово».
3. Після кола всі дії розв'язуються в порядку `nightOrder`: Чарівниця → Мафія → Самітник → Лікар.
   Ціль мафії вибуває, якщо лікар її не врятував.

**Ранок (`morning`):** «Місто прокидається ☀️. Цієї ночі… [нікого не забрали / вибув(ла) Петро]».
- Чи показувати роль того, хто вибув, вирішує налаштування `revealRoleOnElimination` (для дітей за замовчуванням `true`, так простіше).
- Вибулий гравець отримує «останнє слово»: таймер 30 с.

**День, обговорення (`dayDiscussion`):** спільний таймер (за замовчуванням 3 хв, налаштовується 1–5 хв), кнопка «Завершити раніше».
Опція «По черзі»: таймер 30 с на кожного живого гравця в порядку місць.

**День, голосування (`dayVote`):**
- Кожен живий голосує проти одного гравця або «утримуюсь».
- Вибуває той, хто має **найбільше** голосів, і лише якщо в нього більше голосів, ніж «утримались».
- **Нічия між кількома →** `runoff`: 30 с виправдання кожному, потім переголосування лише між ними. Нова нічия означає, що сьогодні ніхто не вибуває.
- Перший день: якщо грає 5–6 людей, голосування є, але кнопка «Пропустити перше голосування» доступна (налаштування).

**Перевірка перемоги** (після кожного ранку та кожного дня):
- Місто перемагає, якщо не лишилося жодної мафії (і Самітника, якщо він є в грі).
- Мафія перемагає, якщо живих мафіозі **≥** живих інших гравців.
- Самітник перемагає, якщо лишився вдвох з будь-ким.

### Крайові випадки
- Лікар вибув: нічне коло все одно включає всіх живих, лікування просто не відбувається.
- Комісар перевіряє того, кого цієї ночі забирає мафія: перевірка все одно спрацьовує.
- Єдиний мафіозі не обрав ціль (технічно неможливо, бо «Готово» без вибору недоступне для ролей з обов'язковою дією; у лікаря вибір обов'язковий, у мирних — ні).
- Усі утрималися: ніхто не вибуває.

### Критерії приймання (A)
1. Гра на 5 гравців від лобі до кінця проходить без ведучого-людини.
2. Для кожної кількості 5–12 автоматично підставляється склад з таблиці.
3. Лікар не може обрати ту саму ціль дві ночі поспіль: кнопка неактивна з підказкою.
4. Умови перемоги перевіряються після кожного вибуття, і гра завершується одразу.
5. Перезавантаження сторінки посеред ночі не губить уже зроблені нічні дії.
6. Редʼюсер покритий тестами: розв'язання ночі, нічия у голосуванні, усі умови перемоги.

## ВАРІАНТ B. Спортивна мафія (адаптація турнірних правил)

### Ідея
Турнірний формат: ролі за замовчуванням не розкриваються, мова суворо за таймером, кандидатів виставляють, мафія «стріляє» за домовленістю. Розвиває логіку, увагу й уміння говорити. Для дітей молодшого віку складно, для підлітків 12+ цікаво.

### Ролі
| Роль | Команда | Вночі |
|---|---|---|
| Дон | «Чорні» (мафія) | Стріляє разом з мафією; окремо шукає Шерифа (бачить «Шериф / не Шериф») |
| Мафія | «Чорні» | Стріляє |
| Шериф | «Червоні» (місто) | Перевіряє одного гравця й бачить «червоний / чорний» |
| Мирний | «Червоні» | «Кого підозрюєш?» (на результат не впливає) |

### Розподіл
| Гравців | Дон | Мафія | Шериф | Мирні |
|---|---|---|---|---|
| **6** | 1 | 0 | 1 | 4 |
| 7 | 1 | 1 | 1 | 4 |
| 8 | 1 | 1 | 1 | 5 |
| 9 | 1 | 1 | 1 | 6 |
| **10 (оригінал)** | 1 | 2 | 1 | 6 |

При 6 гравцях Дон сам: стріляє й шукає Шерифа. Двоє «чорних» проти чотирьох програють майже одразу, тому один.

### Цикл гри
```
lobby → dealRoles → zeroNight → day(1) → night(1) → day(2) → … → gameOver
```

**Нульова ніч (`zeroNight`), без пострілу:**
- Чорні бачать одне одного й погоджують **порядок пострілів**: Дон у своєму ході вводить список цілей «ніч 1, ніч 2, ніч 3». Решта чорних бачать цей список у своєму ході.
- Шериф лише дізнається свою роль, перевірки ще немає.
- Решта проходить коло «для маскування».

**День (`day`):**
1. Оголошення: хто вибув уночі. Перший вибулий має право на **«найкращий хід»**: вказати 3 номери, яких вважає чорними. Це фіксується в лозі й показується в підсумку.
2. **Останнє слово** вибулого: 60 с.
3. **Промови по колу:** кожен живий гравець має 60 с. Перший спікер щодня зсувається на одне місце.
   Під час промови гравець може **виставити** одного кандидата: кнопка «Виставити № …» на екрані таймера, телефон лежить у центрі.
4. **Голосування:** кандидати йдуть у порядку виставлення. Кожен живий голосує лише один раз. Хто не проголосував ні за кого, автоматично віддає голос за останнього кандидата.
   - День 1: якщо виставлено лише одного кандидата, голосування не відбувається.
   - **Нічия:** кандидати з однаковою кількістю голосів отримують по 30 с, потім переголосування між ними. Нова нічия → питання «Вигнати всіх, хто має однакову кількість?» (більшість «за» → вибувають усі, інакше ніхто).
5. Вибулий має останнє слово 60 с.

**Ніч (`night`):**
- Чорні по черзі обирають номер цілі. **Постріл зараховується, лише якщо всі живі чорні обрали одного й того самого гравця.** Інакше «промах», і ніхто не вибуває.
- Дон перевіряє одного гравця на Шерифа.
- Шериф перевіряє одного гравця на «чорний / червоний».
- Лікаря немає, порятунку немає.

**Фоли** (опційно, налаштування `fouls`): кнопка «Фол № …» на екрані дня. 3 фоли = позбавлення наступної промови. 4 фоли = гравець вибуває з гри.

**Перемога:**
- Червоні: усіх чорних вигнано.
- Чорні: чорних **≥** червоних.

### Що робить застосунок у цьому варіанті
Електронний суддя: таймери промов з вібрацією та звуком «10 секунд», черга спікерів, список виставлених кандидатів, підрахунок голосів, облік фолів, нічні дії через передавання телефону.

### Критерії приймання (B)
1. Нульова ніч не містить пострілу. Порядок пострілів Дона видно іншим чорним.
2. Таймер промови автоматично переходить до наступного гравця і щодня зсуває першого спікера.
3. Правило «неголосований голос іде за останнього кандидата» реалізовано й показано на екрані підсумку голосування.
4. Промах при різних цілях у чорних працює коректно.
5. «Найкращий хід» доступний лише першому вибулому вночі.

> **Ризики B:** найдовший і найскладніший варіант. При 6–8 гравцях баланс гірший, ніж в оригіналі на 10 гравців. Дітям складно витримувати формальні промови. Перед реалізацією варто звірити деталі з актуальними правилами ФІІМ.

## ВАРІАНТ C. «Одна ніч» (швидкий формат без вибування)

### Ідея
Лише **одна ніч і один день**. У колоді на 3 картки більше, ніж гравців: ці 3 лежать «у центрі». Уночі деякі ролі підглядають і **міняють картки місцями**, тож гравець може навіть не знати, ким став. Потім 5 хв обговорення, одне спільне голосування — і гру завершено.
**Ніхто не вибуває посеред гри й не сидить без діла.** Партія триває близько 10 хв, тож її легко зіграти ще раз. Найкраще підходить, щоб «відволіктися».

> Механіка «одна ніч + картки в центрі» поширена, але назву, ролі й оформлення робимо **власні**, без запозичення комерційних назв чи артів.

### Ролі (тема «Ліс» / тема «Місто»)
| Роль | Команда | Нічна дія | Порядок |
|---|---|---|---|
| Вовк / Мафіозі | Вовки | Бачить інших вовків. Якщо вовк **один**, може підглянути 1 картку з центру | 1 |
| Поплічник *(5+)* | Вовки | Бачить, хто вовки (вовки його не бачать) | 2 |
| Близнюки *(6+, завжди парою)* | Село | Бачать одне одного | 3 |
| Сова / Детектив | Село | Дивиться картку **одного гравця** або **двох карток з центру** | 4 |
| Лис / Злодій | Село* | Міняє свою картку з карткою іншого гравця й дивиться **нову** свою роль | 5 |
| Бешкетник | Село | Міняє картки **двох інших** гравців, не дивлячись на них | 6 |
| Заєць / Мирний | Село | «Кого підозрюєш?» | — |
| Дивак *(7+)* | Сам за себе | — | — |

\* Команда визначається **фінальною** карткою: якщо Лис забрав картку Вовка, він тепер Вовк.
Дивак перемагає, якщо вигнали саме його. Тоді вовки й село програють, якщо інше не передбачено.

### Колода за кількістю гравців (гравці + 3 картки в центрі)
| Гравців | Колода (карток) |
|---|---|
| **3** | Вовк ×2, Сова, Лис, Бешкетник, Мирний ×1 (6) |
| 4 | Вовк ×2, Сова, Лис, Бешкетник, Мирний ×2 (7) |
| 5 | Вовк ×2, Поплічник, Сова, Лис, Бешкетник, Мирний ×2 (8) |
| 6 | Вовк ×2, Поплічник, Близнюки ×2, Сова, Лис, Бешкетник, Мирний ×1 (9) |
| 7 | Вовк ×2, Поплічник, Близнюки ×2, Сова, Лис, Бешкетник, Дивак, Мирний ×1 (10) |
| 8 | 7 + Мирний (11) |
| 9 | 8 + Мирний (12) |
| 10 | Вовк ×3, Поплічник, Близнюки ×2, Сова, Лис, Бешкетник, Дивак, Мирний ×3 (13) |

### Цикл гри
```
lobby → deal → nightCircle → resolveNight → discussion → vote → reveal → gameOver
```

**Нічне коло (pass-and-play):**
- Кожен гравець отримує телефон і бачить свою **початкову** роль та її дію.
- Порядок проходу кола довільний (за місцями), але **розв'язання** йде в канонічному порядку ролей. Інформація, яку бачить гравець, відповідає моменту його дії в канонічному порядку:
  - Вовк, Поплічник, Близнюки й Сова бачать **початковий** розклад. Їхні ролі діють до будь-яких обмінів, тому показ одразу коректний.
  - Лис бачить свою нову роль одразу: до нього в канонічному порядку ніхто карток не міняв, а Бешкетник діє пізніше.
  - Бешкетник нічого не бачить, тож його обмін просто записується.
- **Тому всю ніч можна пройти одним колом**, а `resolveNight` застосовує обміни в порядку: спочатку Лис, потім Бешкетник.
- Ролі, які потребують фінального стану (наприклад «Безсонний», що дивиться свою картку наприкінці ночі), у MVP **не додаємо**, бо їм потрібне друге коло.

**Обговорення:** таймер 5 хв (3–8, налаштовується). Підказка на екрані: «Можна говорити правду або блефувати. Картки не показуємо!»

**Голосування** (таємне через коло або «на рахунок 3 покажіть пальцем»):
- Кожен вказує на одного **іншого** гравця.
- Вибуває той, хто має найбільше голосів. При **нічиї вибувають усі**, хто має найбільше.
- Якщо кожен отримав рівно 1 голос, ніхто не вибуває.

**Підсумок (`reveal`):**
- Показуються фінальні картки всіх і 3 центральні картки.
- **Хронологія ночі:** «Лис (Оля) обміняв картку з Петром → Оля стала Вовком; Бешкетник (Іра) поміняв Петра й Марка…». Це головний «вау-момент» гри, тож його треба оформити анімацією карток.

**Перемога:**
- Село перемагає, якщо вигнано хоча б одного Вовка. Також перемагає, якщо серед гравців **немає** жодного Вовка (усі в центрі) і ніхто не вибув.
- Вовки (і Поплічник) перемагають, якщо жоден Вовк не вибув, а серед гравців є хоча б один Вовк.
- Якщо вовків серед гравців немає, але Поплічник є: Поплічник перемагає, якщо вигнали когось іншого, не його.
- Дивак перемагає, якщо вигнали його.

### Критерії приймання (C)
1. Партія на 3 гравців повністю грається.
2. `resolveNight` детермінований: для фіксованого розкладу й дій результат завжди однаковий. Покрито тестами з усіма комбінаціями Лис + Бешкетник.
3. Одинокий Вовк може підглянути рівно 1 центральну картку. Якщо вовків двоє, такої опції немає.
4. Команду гравця визначає **фінальна** картка, що видно в підсумку.
5. Усі правила нічиїх у голосуванні реалізовані.
6. Від лобі до підсумку при 5 гравцях проходить не більше 15 хв.

## Можливе розширення для всіх варіантів: гравці-боти
Ідея: розв'язати проблему «нема з ким грати», додавши ботів до мінімуму.
- У варіанті **C** це найреалістичніше. Бот робить нічну дію за простою стратегією й «говорить» шаблонними фразами («Я Сова, бачила, що Петро — Мирний»). Голосує за евристикою.
- У **A** боти можливі, але без живого обговорення гра втрачає сенс.
- Генерацію реплік ботів через LLM можна розглянути окремо, але це вже інший масштаб задачі: сервер, вартість, модерація контенту для дітей.
- **Рекомендація:** не в MVP. Повернутися після запуску режиму «кожен зі свого телефону».
